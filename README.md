## Features of the Pasta King Restaurant Website

### **1) Full Multi-Page Restaurant Website**

The site has a complete navigation structure with:

* **Home**
* **Menu**
* **Build Your Own**
* **About**
* **Gallery**
* **Reservations**

---

### **2) Modern Landing Page (Home)**

The homepage is built like a real high-end restaurant website:

* Strong hero section with clear CTA buttons (**View Full Menu**, **Book a Table**)
* “Chef’s Signature Specials” section
* “Popular with Guests” section
* Customer testimonials section
* Strong branding and consistent visual style

---

### **3) Online Menu + Cart System**

The menu page supports:

* Menu categories/tabs (e.g. All, Chef’s Specials, Meat Lovers, Seafood, Vegetarian)
* Dish cards with name, description, and price (GHS)
* **Add to Order** functionality
* A live **cart panel** showing subtotal and total
* A checkout action (**Confirm Order**)
* Delivery details input (delivery address)

---

### **4) “Build Your Own Bowl” Custom Builder**

This is one of the strongest features.

Users can create a custom bowl using a step-by-step flow:

1. **Select Base** (e.g. spaghetti, penne, rice, etc.)
2. **Pick Sauce**
3. **Add Protein**
4. **Finish with Toppings**

And it includes:

* A live **order summary**
* A running **total price**
* **Add to Cart** button

---

### **5) Reservation Booking UI**

The reservations page is clean and realistic:

* Step-based booking flow
* Select number of guests
* Calendar date picker
* Time slot selection
* Contact form (name, email, phone)
* Special requests field
* Reservation summary + confirm button

---

### **6) Gallery with Category Filtering**

The gallery page includes:

* A responsive photo grid
* Filter chips/categories like:

  * All
  * Dishes
  * Interior
  * Kitchen
  * Happy Faces

---

### **7) About Page / Brand Storytelling**

The About page includes:

* Restaurant story (“From Accra to Rome” theme)
* Values section (Bold spices, Fresh pasta, Community first)
* Founder spotlight (“Chef Kwame Mensah”)

This makes the project feel like a real brand, not just a template.

---

### **8) Dark Mode Toggle**

There’s a theme toggle in the navbar (light/dark mode support).

---

### **9) Floating AI Concierge (Key Feature)**

The site includes an in-built AI chatbot called:

**Kwame’s Concierge — Live Concierge Mode**

It can:

1. **Guide users to build a custom bowl**
2. **Add menu items to cart**
3. **Make reservations**
4. **Provide restaurant info (location + opening hours)**
5. **Navigate the site (Menu, Gallery, Reservations pages)**

This is a standout portfolio feature because it mixes **UX + AI + product thinking**.

---

### **10) Responsive + Polished UI**

The design is:

* Clean and premium
* Mobile-friendly
* Consistent spacing, typography, and layout
* Strong CTA placement (Order Online button, Book a Table, etc.)
